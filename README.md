# ربات دفتر نت‌یار مهاجر

نسخه توسعه‌یافته شامل:
- پنل مدیریت داخل تلگرام
- مدیریت خدمات و ساخت مراحل قابل تنظیم
- دریافت متن، عکس، فایل، شماره تماس و رسید پرداخت
- ثبت و پیگیری درخواست‌ها
- اعلان فوری برای مدیر
- تغییر وضعیت درخواست و اطلاع‌رسانی به مشتری
- گزارش بین دو تاریخ با مشخصات مشتری و خدمت
- مدیریت متن‌های اصلی و پیام همگانی
- ذخیره اطلاعات در SQLite

## متغیرهای Railway
- `BOT_TOKEN`: توکن BotFather
- `ADMIN_IDS`: شناسه عددی تلگرام مدیر/مدیران، جداشده با کاما؛ مثال `123456789,987654321`
- `DB_PATH`: اختیاری، پیش‌فرض `netyar.db`

**نکته:** برای اینکه SQLite با حذف/بازساخت کانتینر Railway از بین نرود، DB_PATH را روی یک Volume دائمی Railway قرار دهید.
